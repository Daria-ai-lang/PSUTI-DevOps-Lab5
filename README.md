# Лабораторная работа 5. Вариант 19

**Задание:** Разработать интерфейс для проверки одновременного бронирования последних билетов на одно событие. Показывать успешные и отклонённые запросы и проверять, что число проданных билетов не превышает квоту.

## Запуск проекта

Для запуска нужен Docker. В корне проекта выполните:
```bash
docker compose up -d --build

## Как проверить работу

1. Откройте страницу фронтенда: [http://localhost:8080](http://localhost:8080)
2. На странице появится выпадающий список с событиями из базы. Выберите любое событие.
3. Нажмите кнопку «Забронировать 10 билетов ОДНОВРЕМЕННО».
4. В таблице результатов вы увидите, что запросы обрабатываются параллельно: часть проходит успешно (зеленые, код 201), а часть отклоняется с ошибкой `INSUFFICIENT_TICKETS` (красные, код 409), если свободных билетов меньше 10. Это доказывает, что система корректно обрабатывает конкурентные запросы и не позволяет продать билетов больше, чем есть в наличии.
